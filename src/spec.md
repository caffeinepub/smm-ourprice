# Specification

## Summary
**Goal:** Launch a complete social media services marketplace (IBAZEX Store) with customer-facing catalog and admin management system.

**Planned changes:**
- Create Arabic RTL homepage showcasing IBAZEX brand and social media services value proposition
- Build services catalog page displaying followers, likes, and views for Facebook, Instagram, YouTube, and TikTok in table format
- Implement backend data model and API endpoints for managing services (platform, type, price, description, availability)
- Create authenticated admin dashboard for managing service prices, adding new services, and controlling availability
- Implement customer order system with order form and backend order management
- Integrate Internet Identity authentication for secure user and admin access
- Apply modern, professional design theme reflecting digital marketing industry with cohesive color palette and typography

**User-visible outcome:** Customers can browse social media services in Arabic, place orders for followers/likes/views, while administrators can securely manage the service catalog and view orders through an authenticated dashboard.
